# IELTS Studio · 雅思学习室

一个无需账号、无需安装依赖的雅思学习网页。以主题词汇、主动回忆、间隔复习和写作运用为核心，面向希望提升学术英语表达的中文学习者。

## 打开项目

1. 在 GitHub 仓库页面点击绿色 **Code → Download ZIP**。
2. 解压压缩包，进入项目文件夹。
3. 双击 `index.html`，或右键选择 **打开方式 → Microsoft Edge / Chrome**。

GitHub 的文件页面只展示源码，不会直接运行网页。推荐长期使用时按下文启动固定地址的本地服务器，便于稳定保存学习记录。

## 简洁界面

顶部只保留四个入口：**学习、词库、写作、设置**。移除大幅标语、装饰图形和侧边导航，把词卡与主要操作放在首屏。

| 入口 | 保留的能力 |
| --- | --- |
| 学习 | 主题选择、翻卡回忆、中文提示拼写、发音、收藏、四档复习评价、队列刷新、每日目标 |
| 词库 | 全部词条、中文与英文搜索、搭配搜索、主题筛选、收藏筛选、发音 |
| 写作 | 四个主题题目、搭配提示、词数统计、分主题草稿自动保存与导出 |
| 设置 | 每日目标、新词上限、英美发音偏好、完整备份导出与校验导入 |

今日次数、到期词数、已学词数和连续天数以紧凑统计栏显示。移动端自动改为单列。

## 已实现

- **40 个示例词条、4 个主题**：环境 15 词、教育 8 词、科技 7 词、社会 10 词。
- 每词包含音标、词性、中文释义、学术搭配、自拟考试风格例句和近反义表达；没有直接反义词时留空。
- 翻卡回忆、中文提示拼写、浏览器英美发音、搜索、主题筛选和收藏。
- 到期旧词优先，每日新词上限跨主题累计；每日目标、学习次数和连续学习天数。
- 4 道自拟 Writing Task 2 练习题，分主题保存草稿、英文词数统计、纯文本导出。
- 本地进度自动保存、JSON 备份导入导出。导入时校验结构，保留较新的复习记录和当前已有草稿。
- 响应式布局、键盘可访问的原生表单与按钮、无第三方页面资源。

## 开始使用

直接打开 `index.html` 即可使用主体功能。推荐通过固定的本地 HTTP 地址使用，避免浏览器对 `file://` 存储的不同处理。

安装 [Node.js 20+](https://nodejs.org/)，在项目目录执行：

```bash
npm start
```

打开 http://127.0.0.1:5173 。没有运行时依赖，无需 `npm install`。

```bash
npm run check
npm test
```

## 复习规则

这是透明、简化的间隔复习实现，**不是 FSRS 或完整 SM-2**：

| 评价 | 下次复习 |
| --- | --- |
| 没记住 | 10 分钟后 |
| 有点难 | 至少 1 天，或上次间隔 × 1.2 |
| 记住了 | 初次 1 天，之后至少 3 天或上次间隔 × 2 |
| 很熟悉 | 至少 4 天，或上次间隔 × 3 |

最长间隔 365 天。每次评价记录一次回忆次数。“没记住”的词在到期后点击重新安排队列即可再学；未到期的词仍可在词库查阅。

每日新词数按首次学习日期计算，跨主题共享上限。日期和连续天数使用设备本地日历。今日学习目标是回忆次数，不是新词数量。

## 数据与隐私

进度、收藏、计划和作文保存在浏览器 `localStorage`，键为 `ielts-studio-v1`。应用不提供账号或云同步。不同域名、端口、浏览器之间不共享记录；请在换设备或清理浏览器前导出备份。系统朗读由浏览器和操作系统提供，是否使用联网语音取决于系统语音配置。

备份导入采用合并方式：复习记录选 `last` 更新的版本，同一天回忆次数取较大值，收藏去重，当前已有作文和计划保留。没有设置自动抹除学习数据的按钮。

## 内容范围

词条、例句和题目为 AI 辅助编写的练习材料，未经过语言教师逐条审核。词汇难度不等于官方雅思分数等级，近反义表达需结合语境；不是官方雅思词表，不承诺提分。当前版本专注词汇和写作练习，不包含完整听力、阅读、口语模拟考试或自动评分。

## 项目结构

```text
index.html          页面与导航
styles.css          桌面与移动布局
words.js            主题、词条、写作题目
core.js             复习算法、队列、备份校验与合并
app.js              浏览器交互与本地存储
server.cjs          只提供前端文件的本地服务器
tests/core.test.cjs  数据、调度、备份和 HTTP 测试
```

新增词条：编辑 `words.js` 的 `rows`，保持单词 ID 唯一，补齐字段并运行测试。页面可部署到任意静态托管服务，无需后端；本次交付只保存源码，不自动公开发布学习网站。
